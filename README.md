# Pháp Lục Hoà — Landing Page

🪷 **Sáu Phép Hoà Kính** — Landing page chương trình Pháp Lục Hoà

## Giới thiệu

Landing page giới thiệu chương trình Pháp Lục Hoà — Sáu nguyên tắc sống hoà hợp do Đức Phật dạy dỗ để xây dựng sự đoàn kết, an vui và thanh tịnh.

## Tính năng

- 🎨 Thiết kế Phật pháp (Gold / Saffron / Cream)
- 📱 Responsive (Desktop, Tablet, Mobile)
- 📝 Form đăng ký tích hợp Google Sheets
- ❓ FAQ accordion
- ✨ Scroll animations
- 🪷 Trang Thank You sau đăng ký

## Cấu trúc

```
├── index.html          # Trang chính
├── thank-you.html      # Trang cảm ơn
├── styles.css          # CSS
├── script.js           # JavaScript
└── images/             # Hình ảnh minh hoạ
```

## Deploy

Trang web được host trên GitHub Pages.
